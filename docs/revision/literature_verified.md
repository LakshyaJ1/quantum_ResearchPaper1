# Verified literature and the defensible scope of this revision

Verified on 26 September 2026 local time (25-26 September UTC) using primary publisher, author-preprint, standards and project sources. Fetch manifests in `sources/*_fetch.json` record requested URL, final URL, status, byte count, UTC time and SHA-256. A successful HTTP status was not accepted without checking title/content. This is a focused comparison, not an exhaustive systematic review and not independent reproduction of other authors' results.

The revised paper can contribute an auditable **empirical evaluation** of weighted attack budget, interruption duration, paired excess entitlement/payload loss, and a constrained learned grade-allocation policy across topologies and loads. Finite key reservoirs, key-depletion time, buffering through downtime, weighted security value, hybrid fallback, safe RL and shields all have prior art; none should be advertised as invented here. The combined evaluation is a candidate distinctive contribution whose strength depends on the completed experiments, not on an unqualified claim that no prior paper exists.

## Legacy buffer provenance and units

The source path cited by the older project notes exists in the legacy repository, not the current `qkdnetsim` repository. The immutable [SECOQC example](https://github.com/QKDNetSim/qkdnetsim-v1-old/blob/394bfed1b1a84b2b11cd5aec20c748df3204757b/scratch/secoqc_p2p_qkd_system.cc#L232) assigns the requested triple at lines 234-236 and initializes that link at its maximum at line 237; other example links can have different minima or initial stocks (for example, line 245 uses 1,548,576 bits). The current manuscript can therefore describe these as parameters selected from a legacy example and retain the initial-stock sensitivity, without claiming that the example universally initializes every link identically.

The maximum is **52,428,800 bits = 50 Mibit = 6.25 MiB**, approximately 52.43 Mbit. The selected minimum is 1,048,576 bits = 1 Mibit = 0.125 MiB. Neither this code reference nor the word SECOQC proves that this minimum was a deployed 2 MiB authentication reserve; that is a different number and a separate empirical claim.

The [legacy buffer implementation](https://github.com/QKDNetSim/qkdnetsim-v1-old/blob/394bfed1b1a84b2b11cd5aec20c748df3204757b/src/qkd/model/qkd-buffer.cc#L227) declares bit units for incoming content, has the four stock states at lines 414-436, and refuses an entire incoming block when adding it would reach or exceed capacity at lines 237-245. A continuous reservoir that fills remaining space and discards only excess is therefore a related abstraction, not a verbatim replication of every boundary behavior. The raw SECOQC example has SHA-256 `6e827c0ee0035fb5211bef5d3c28096724e3586c9155c243cb809a55050d6965`, and the buffer source has SHA-256 `12fe0a0cfeed636c6141188419676fe36e68649f9edf2ef2f08d24b41a36d1f2`.

## Recommended claim language and evidence boundary

A defensible contribution statement is: **We evaluate how interruption duration and heterogeneous link budgets translate into excess assurance loss in finite-reservoir trusted-relay networks, and test whether an interpretable learned allocator improves service under explicit class-specific downgrade permissions.** Keep the statement empirical; only name conditions actually run, and report unfavorable or null learned-policy outcomes as readily as improvements.

For a reservoir-preserving scenario, model a QBER-triggered abort as zero new secret-key production while previously generated, authenticated, synchronized and unexpired keys remain available. State explicitly that the modeled attack does not compromise old key material, and show a purge/expiry alternative if drawing comparisons to implementations that intentionally invalidate stock. Classical data-path loss prevents delivery regardless of pre-positioned fallback keys; classical key-establishment failure alone is a different scenario. This distinction follows from architecture and the stated policy, not from a new security proof.

Avoid stating that the weighted min-cut alone determines finite-horizon forced loss. Stored key can bridge a short interruption, while traffic endpoints, payload, per-link cost, reserve/expiry policy and classical reachability determine what service is actually lost. A minimum cut in the generation graph is a structural reference; a measured attack budget producing a specified excess loss by a deadline is an empirical quantity.

The lambda crossing between two measured policies is derived algebraically from their objective components. Learning/search is needed only to produce candidate policies, not to derive the crossing once outcomes are known. A 104.8% comparison is a ratio to the best candidate encountered under a particular budget, not an optimality guarantee or a proof that ML is unnecessary. Claims that short-horizon training caused a failure need a controlled short/long-horizon or initial-state ablation with otherwise comparable training effort.

For the new all-class runtime gate, report both proposed and executed actions and the exact exposure allowance update. Prefix-budget enforcement under declared weights can be tested deterministically; it does not establish a deployment-level security guarantee, the correctness of the class weights, or robustness to arbitrary model misspecification. Keep objective weights, authorized exceptions and hard prohibitions distinct so the result cannot hide violations in a favorable scalar score.
